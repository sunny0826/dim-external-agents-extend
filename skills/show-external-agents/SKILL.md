# Show External Agents（打开外部 Agent 面板）

本技能只做一件事：**打开面板**。

## 做什么

调用一次 `open_agent_run_log`，然后用一句话确认面板已打开。

不要反问用户"想看哪个任务 / 什么状态"——面板本身就是入口，筛选在面板里。

## 不做什么

- 不调 `list_agent_runs` / `read_agent_run` 去查任务、读日志；
- 不调 `show_external_agents` 显示内联卡片（那是"在会话里看"，不是"打开面板"）；
- 不解读面板内容、不总结任务进展。

## 面板打开后怎么用（用户问起时再说）

- 默认视图是**本会话 + 只看运行中**；要看历史，点列表页右上角「筛选」，勾选 已完成 / 已取消 / 失败 或「全部会话」；
- 点列表里的任务进入日志详情页：运行中每 2s 增量刷新，「跟随」开关控制自动滚动；
- 若用户接着问某个任务的具体情况（跑到哪了 / 结果如何 / 为什么失败），那属于 `external-agents-extend` 技能——用 `read_agent_run` 读日志后再回答，不要在本技能里顺手做。
